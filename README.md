# 내 가계부 (웹앱)

폰의 홈 화면에 추가해서 앱처럼 쓰는 가계부입니다. 서버 없이 폰 안에만 저장됩니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다. (예: `gagyebu`, Public)
2. 저장소 화면에서 **Add file > Upload files**를 눌러 이 폴더 안의 파일을 모두 끌어다 놓습니다.
   `index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더가 저장소 맨 위(루트)에 있어야 합니다.
3. **Commit changes**를 누릅니다.
4. **Settings > Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하고 Save를 누릅니다.
5. 1~2분 뒤 `https://내아이디.github.io/gagyebu/` 주소가 생깁니다.

## 아이폰에 설치

1. **사파리**로 위 주소를 엽니다. (크롬이 아니라 사파리여야 합니다.)
2. 공유 버튼 > **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 아이콘으로 실행합니다.

## 꼭 지켜 주세요

- 데이터는 이 폰의 브라우저 저장소에만 있습니다. 홈 화면 아이콘 삭제, 사파리 웹사이트 데이터 삭제, 폰 교체 시 사라질 수 있습니다.
- **설정 > 백업 파일 저장**으로 한 달에 한 번 백업해서 파일 앱이나 iCloud Drive에 보관하세요. 한 달 넘게 백업하지 않으면 달력 화면에 알림이 뜹니다.
- 복원은 **설정 > 백업 파일 불러오기**입니다.

## 앱을 수정해서 다시 올릴 때

`index.html`을 바꿔 올린 뒤 `sw.js` 맨 위의 `gagyebu-v1`을 `gagyebu-v2`처럼 올려 주세요. 그래야 폰에 저장된 옛 버전이 새 버전으로 바뀝니다.
